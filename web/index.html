Your route library, in your browser

rerouter keeps a library of GPX routes for gravel, road and mountain biking, and hiking: stats, a map, filters, finding routes that overlap, and combining two routes into a new one.

Everything you add is stored in this browser only, on this device. Nothing is uploaded. The connector routing and the surface estimate ask a BRouter server for directions (the public one at brouter.de by default); only the points being routed are sent. The ride weather asks Open-Meteo for the forecast at a few points along the route.

Your library stays when you refresh the page (even a hard refresh) or close the browser, but not when you clear this site's data or use a private window. So download a backup now and then (Utilities › Library & settings).

You're using Safari. Safari deletes the data of a website after 7 days of using Safari without visiting that site, so in Safari your library only lasts while you use rerouter at least once a week. Keep a backup, or use another browser (Firefox, Chrome, Edge) for rerouter.

Just looking around? Load a set of example routes to try the map, the weather and combining routes right away. You can remove them again at any time.

        Where your routes are

        Your library lives in this browser's storage on this device: .

        Safe: refreshing the page (a hard refresh too), closing the tab or the browser, restarting the computer, and new versions of rerouter.

        Gone, or out of reach:

        • when you clear this site's data ("cookies and other site data" when clearing browsing data);
        • in a private or incognito window: everything goes when the window closes;
        • in Safari (Mac, iPhone, iPad): after 7 days of using Safari without opening rerouter;
        • when the disk is nearly full and the browser frees up space (unless it agreed to keep it, see above);
        • in another browser, browser profile or device: each has its own, separate library.

        The library belongs to the address : clearing the site data of that address clears it, also for other pages on the same address.

        So: download a backup now and then, and keep it outside the browser (e.g. in a cloud folder). A backup also moves the library to another browser or device.

        Backup

        One zip file with every route, your ratings, tags and notes, and all original GPX files. The browser version and the server version use the same backups, so this also moves a library between them.

        To share only some routes, select them in the library and choose Export set…. Such a zip (or a whole backup) can also be added to a library, keeping the routes that are already there.

        Example routes

        Sets of routes to start with. They are added to your library (routes you already have are skipped).

        Settings

        The public server at brouter.de is shared by many people: please don't estimate the surface of hundreds of routes in one go there. Running your own BRouter (e.g. with docker) and filling in its address here works too, as long as it allows requests from this page (CORS).
