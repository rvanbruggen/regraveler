# Changelog

| Version | Date | Changes |
|---|---|---|
| **0.16.0** | 2026-09-28 | **Places (POIs)**: a new *Places* tab to import places from Google My Maps (KML/KMZ, or a layer's CSV export) or any CSV with lat/lon, with a suggested category per layer (from the layer name or its icons; a one-place layer such as a home address is left out unless ticked), lists you can show or hide, and categories (built-in, including *Frituur*, and your own, with symbol and colour). Places show on every map (layer button › *Places*), with a popup editor; **＋ Place** on the Map adds one by clicking. The route panel lists the **places along the route** (km and distance off it, within 200 m). New document store for this (IndexedDB version 2; `library_docs` and `/api/docs` on the server; `docs` in backups) |
| **0.15.0** | 2026-09-28 | **TCX and FIT import** (Garmin, Wahoo and other devices; also `.fit.gz` / `.tcx.gz` as in a Strava bulk export), with an own FIT decoder. Originals are stored as they are (also by the server, in backups and in the `gpx/` folder scan); *Download GPX* writes a GPX for them and *Original .fit/.tcx* gives the file. The activity comes from the file when it says so (run/walk → hiking; FIT mountain, road or gravel sub-sport). **Recorded rides**: a FIT or TCX activity that covers at least 80% of a library route can be logged on that route (*Log as ridden*, the route panel lists the dates) instead of imported |
| **0.14.0** | 2026-09-28 | **Elevation profile** in the route panel: the smoothed profile the elevation gain is computed from, with climbs coloured by gradient per 100 m (3–6 %, 6–9 %, 9 % and steeper). Hover the chart for the km, elevation and gradient there and a marker on the map; hover the route on the map to see that point on the chart. Also: `docs/ROADMAP.md` with the plan for the next releases |
| **0.13.0** | 2026-09-28 | Map styles: every map has a layer button (top right) to switch between OpenStreetMap, **CyclOSM** (cycling, unpaved roads dashed), **OpenTopoMap** (contour lines), the Belgian **NGI topo** map and **Esri satellite**, with the **Waymarked Trails** hiking and cycling routes as optional overlays. All free, no key. The choice applies to every map and is remembered in the browser; the list is `MAP_STYLES` / `MAP_OVERLAYS` in `web/js/config.js` |
| **0.12.0** | 2026-09-27 | Combine: new pattern **Out on A, back on B** (ride A from its start to a crossing, switch to B and ride B back to its start; picked automatically when the two routes start within 1 km), a clear choice between the three patterns with an explanation of each, and **Your ride**: the combined route described step by step |
| **0.11.0** | 2026-09-27 | *Utilities › Import from a link*: paste a link to a public **RideWithGPS** route or ride, or a **Komoot** tour (also private tours shared with a `share_token` link). rerouter fetches it and pre-fills the source, activity, notes and (optionally) the paved % from the service's surface data, then imports it like a GPX file (naming setting, duplicate check). **Strava** links get the export link to download while signed in; the chosen file is imported with the Strava link as source. **Any other link to a GPX file** is fetched and imported unchanged: by the page where the site allows it, else by the server (`/api/fetch-gpx`: public internet addresses only, GPX files only, `LINK_FETCH_TIMEOUT_S` / `LINK_FETCH_MAX_BYTES`) |
| **0.10.0** | 2026-09-27 | Route sets: *Export set…* in the library's selection bar writes a rerouter zip with the selected routes, their details and original GPX files (a name and description for the set; *Leave out my notes and quality ratings*, on by default). *Library & settings › Add routes from a zip…* adds a set or a whole backup to a library without replacing it (new ids, routes already there skipped, "derived from" links and "not duplicates" decisions kept); works between the server and the browser version. Example sets: zips in `web/data/seeds/` (listed by `web/tools/build_seeds.py`) are offered to visitors on the welcome screen and under *Library & settings › Example routes* |
| **0.9.2** | 2026-09-27 | Fix: importing on the self-hosted version failed with "Cannot read properties of undefined (reading 'digest')" when the page is opened over plain HTTP (browsers only offer `crypto.subtle` on HTTPS or localhost); a JavaScript SHA-256 is used there instead |
| **0.9.1** | 2026-09-27 | New activity: mountain biking (library, filters, import, route panel, selections; the combiner routes its connectors with BRouter's `mtb` profile, ride weather starts at 15 km/h) |
| **0.9.0** | 2026-09-27 | New utility **Ride weather**: the forecast along a route for the day you ride it (Open-Meteo, free, no key; today and the next 15 days, later days politely blocked). Pick the day in a calendar with daily weather, then the start time and your average speed (remembered per activity); every point along the route is read at the moment you pass it. Temperature range, rain on the way and its chance, wind and gusts, km into the wind and with it behind you; the map colours the route by headwind / crosswind / tailwind, with wind arrows. A table compares start times from 06:00 to 20:00, and the panel suggests riding the route the other way round when that is clearly easier on the wind. "Weather…" in the route panel |
| **0.8.3** | 2026-09-27 | Route names: place data for Italy and Romania added, and names are now local everywhere (the country's own language; in Belgium Dutch in Flanders and Brussels, French in Wallonia; official names in Luxembourg) instead of Dutch names abroad: Köln, Paris, Milano, București. Zoniënwoud keeps its Dutch name (its GeoNames point lies just inside Wallonia). Seats of government count as towns (Den Haag was missing) |
| **0.8.2** | 2026-09-27 | Browser version: what keeps and what wipes the library stored in the browser (a refresh keeps it; clearing site data, private windows, Safari after 7 days without a visit, low disk space and another browser or device don't), on the welcome screen, in *Library & settings* and in a new README section. Safari gets a warning on the welcome screen and a backup reminder after 7 days instead of 30. README: link to the live GitHub Pages version |
| **0.8.1** | 2026-09-27 | Start-up: the page shows only "Loading your routes…" until it knows whether it runs on a server or in the browser, instead of briefly showing the browser version's texts and an empty library on the self-hosted version |
| **0.8.0** | 2026-09-27 | One codebase: all route logic (GPX parsing, stats, names, combiner, similarity, surface) now runs in the page (`web/`, JavaScript), which runs two ways: self-hosted, with a thin Python server that stores the library (SQLite + the GPX folder) and proxies BRouter, or as a static site (GitHub Pages workflow) with the library in the browser and the public BRouter. Shared backup format (Library & settings: backup, restore, BRouter server, settings). A 0.7.x library moves to the new store by itself at start-up (old tables untouched). Import: folders and zip files; files already in the server's `gpx/` folder can be added from the Import screen (duplicates and unreadable files are remembered, *Ignore them*); save conflicts between two open pages are refused. Removed: the Python route logic and its dependencies, the CLI import (now backup / restore / migrate) |
| **0.7.2** | 2026-09-26 | README: screenshots of every major feature (library, route panel, rename, map, combine, change start point, duplicates, import) and the script that retakes them |
| **0.7.1** | 2026-09-26 | Import: tags for the whole batch plus extra tags per file (Import screen), and `--tags` for the CLI import |
| **0.7.0** | 2026-09-26 | Utilities menu in the header: Combine and Duplicates moved into it. New utility **Change start point**: start a loop route anywhere on the loop (click, drag or slider; optionally the other way round), preview with stats and start town, download the GPX or save as a new derived route (tags, activity, rating, paved % and source copied; marked as "not duplicates" of the original). "Change start…" in a loop's detail panel |
| **0.6.0** | 2026-09-26 | Renamed from regraveler to **rerouter** (same logo): routes for gravel cycling, road cycling and hiking. New activity field (gravel / road / hiking): filter and column in the library, set per route or for a selection, batch and per-file setting on import (CLI `--activity`), and it picks the combiner's routing profile (gravel, fastbike, hiking-mountain). Existing routes start as gravel |
